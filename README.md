# CalculateFreelance

Free tax calculator for freelancers and 1099 contractors. Built for the US self-employment tax system.

Live at [calculatefreelance.com](https://calculatefreelance.com)

## What it does

- **1099 Tax Calculator** — estimates federal, state, and self-employment taxes for contractors and freelancers. Updated for 2026 tax brackets. [calculatefreelance.com/1099-tax-calculator](https://calculatefreelance.com/1099-tax-calculator)
- **LLC Tax Calculator** — shows how much you save in SE taxes by electing S-Corp status. [calculatefreelance.com/llc-tax-calculator](https://calculatefreelance.com/llc-tax-calculator)
- **W2 vs 1099 Calculator** — converts W2 salary to 1099 equivalent rate and compares true take-home pay. [calculatefreelance.com/compare/1099-vs-w2](https://calculatefreelance.com/compare/1099-vs-w2)

## Tech stack

- Next.js 15
- TypeScript
- Tailwind CSS

## Running locally

```bash
npm run dev
```
